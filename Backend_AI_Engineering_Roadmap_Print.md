## Capstone Project Ideas

After completing the roadmap, build one of these:

1. **AI-Powered SaaS** - Full-stack app with AI features (like Lumienzo!)
2. **Research Agent** - Autonomous agent that researches and writes reports
3. **Code Assistant** - RAG over codebase + agent that can edit files
4. **Multi-modal App** - Combine text, image, and voice AI
5. **Open Source Tool** - Contribute to LangChain/LlamaIndex ecosystem
